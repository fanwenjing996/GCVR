# GCVR: Confidence-Aware Viral Identification through Graph Propagation and Functional Priors

GCVR (Graph-guided Confidence-aware Viral Refinement) is a graph-based framework for viral sequence identification from metagenomic contigs.

GCVR starts from initial viral probability scores generated by PPR-Meta and refines these predictions using two complementary contig graphs:

- **MKNN graph** (mutual k-nearest-neighbor), which captures direct sequence-similarity relationships between contigs;
- **SNN graph** (shared-nearest-neighbor), which captures neighborhood-level structural consistency.

PHROG-derived functional evidence is incorporated as complementary biological information during confidence-aware propagation. GCVR is designed to improve viral identification in fragmented metagenomic assemblies, with particular consideration of short and low-information contigs.

## Requirements

The recommended software environment is provided in `environment.yml`.

```bash
conda env create -f environment.yml
conda activate gcvr
```

## Input Data

GCVR uses the following information for each contig:

- contig sequence
- contig length
- GC content
- initial viral probability from PPR-Meta
- PHROG-derived functional evidence

The master table generated by the preprocessing pipeline contains information such as:

```text
contig  length  gc_content  predict_score  func_0  func_1 ... func_8
```

For benchmark evaluation, a `label` column is also required.

The `predict_score` represents the initial viral probability generated by PPR-Meta.

## PHROG Functional Evidence Preparation

GCVR uses PHROG-derived functional evidence as complementary biological information during confidence-aware propagation. The PHROG evidence is generated from the input contig sequences through ORF prediction and protein-level HMM searches.

### Step 1 — ORF Prediction

First, predict open reading frames (ORFs) from the input contigs and translate them into protein sequences using Prodigal

### Step 2 — PHROG HMM Search

Search the predicted proteins against the PHROG HMM database using HMMER.

```bash
hmmsearch --cpu 20 \
  --tblout <phrog_hits.tbl> \
  <phrog_hmm_database> \
  <proteins.faa>
```

The PHROG HMM database can be obtained from the PHROG resource. The HMM database contains profile HMMs representing different viral protein families.

### Step 3 — Select the Best PHROG Hit

For each predicted ORF, retain its best PHROG hit from the HMMER search results and map the corresponding PHROG identifier to its functional category using the PHROG annotation table.

The resulting file used by GCVR is:

```text
phrog_hits_best_per_orf.tsv
```

This file provides the ORF-level PHROG functional evidence required by the GCVR preprocessing pipeline.

## Pipeline

### Step 1 — 3-mer Feature Extraction

Each contig is represented using a 64-dimensional 3-mer composition vector.

```bash
python graph/extract_kmer.py <input.fasta>
```

The script generates the 3-mer feature matrix and the corresponding contig identifiers.

### Step 2 — Master Table Construction

The master table integrates sequence characteristics, PPR-Meta prediction scores, and PHROG-derived functional information.

```bash
python graph/build_master.py \
  --fasta <input.fasta> \
  --phrog <phrog_hits_best_per_orf.tsv> \
  --ppr <ppr_results.csv> \
  --kmer_id <kmer_ids.csv> \
  --output <master_table.csv>
```

The PPR-Meta result file should provide the contig identifier and the corresponding initial viral probability. 

### Step 3 — MKNN Graph Construction

The MKNN graph captures direct sequence-similarity relationships between contigs. The graph is constructed from cosine similarity between the 3-mer representations.

```bash
python graph/similarity_graph_gen.py \
  --master <master_table.csv> \
  --kmer <3mer.npy> \
  --output <mknn_edges.tsv>
```

The implementation uses mutual nearest-neighbor relationships together with sequence characteristics such as contig length and GC content to define graph connections.

### Step 4 — SNN Graph Construction

The SNN graph captures neighborhood-level structural consistency between contigs. Instead of considering only the direct similarity between two contigs, SNN considers the overlap between their local similarity neighborhoods.

```bash
python graph/build_snn_graph.py \
  --master <master_table.csv> \
  --kmer <3mer.npy> \
  --output <snn_edges.tsv>
```

### Step 5 — Confidence-Aware Propagation

Propagation is performed independently on the MKNN and SNN graphs.

**MKNN branch**

```bash
python correction/propagate.py \
  --master <master_table.csv> \
  --edges <mknn_edges.tsv> \
  --output <mknn_result.tsv>
```

**SNN branch**

```bash
python correction/propagate.py \
  --master <master_table.csv> \
  --edges <snn_edges.tsv> \
  --output <snn_result.tsv>
```

The propagation procedure uses the initial prediction confidence and neighborhood consistency to regulate information propagation. PHROG-derived functional evidence is incorporated as complementary biological information.

### Step 6 — Score Fusion

After independent propagation on the MKNN and SNN graphs, the two refined prediction scores are combined to obtain the final GCVR score.

```bash
python correction/ensemble.py \
  --mknn <mknn_result.tsv> \
  --snn <snn_result.tsv> \
  --output <final_result.tsv> \
  --weight 0.5
```

The `--weight` parameter controls the contribution of the two graph branches. A value of `0.5` assigns equal weight to the refined MKNN and SNN scores for the corresponding fusion setting.
